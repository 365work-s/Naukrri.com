How to Configure Netlify Identity with GitHub

Step 1: Deploy to Netlify

Push your site to a GitHub repository, then connect it to Netlify:

// In your Netlify dashboard:
// 1. Click "Add new site" > "Import an existing project"
// 2. Connect to your GitHub repository
// 3. Configure build settings (if needed) and deploy

Step 2: Enable Identity Service

In your Netlify site dashboard:

// 1. Go to "Identity" > "Settings"
// 2. Click "Enable Identity"
// 3. Configure registration preferences
// 4. Add external providers (GitHub, Google, etc.) if desired

Step 3: Add Site URL to Identity Settings

Add your site URL to the Identity configuration:

// In Identity settings:
// 1. Go to "Registration" > "External providers"
// 2. Add your site URL to allowed domains
// 3. Save changes

Step 4: Add Netlify Identity Widget

Include the Netlify Identity script in your HTML:

<script src="https://identity.netlify.com/v1/netlify-identity-widget.js"></script>

Step 5: Initialize Netlify Identity

Add this JavaScript code to handle authentication:

// Initialize Netlify Identity
if (window.netlifyIdentity) {
  window.netlifyIdentity.on("init", user => {
    if (!user) {
      window.netlifyIdentity.on("login", () => {
        document.location.href = "/admin/";
      });
    }
  });
}
